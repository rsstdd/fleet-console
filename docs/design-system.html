Fleet control, without lying.

Every status token maps to a value the canonical envelope can carry, and no token exists for a state the adapters cannot produce. Freshness is expressed by emphasis rather than by hue, so a value that is no longer current cannot be mistaken for one that is. The accent marks the tenant and nothing else.

01 — Tenants

One switch, three consequences

Dark and light are not a user preference. They are the two tenant profiles, and switching tenant changes the wordmark, the theme and the available panels together, all from configuration. Use the control in the header. Tenant B runs the light profile and has the water-level panel gated off.

02 — Color

Surfaces, accent, status

Both profiles share the same roles and only the values change. The accent is tenant-supplied and never encodes state. Feedback tokens are aliases of status tokens rather than independent values, because two palettes carrying the same colours drift the moment one is adjusted.

04 — Status

Six variants, all reachable from the contract

Five come from the canonical status enum and one, degraded, comes from health severity. Maintenance and info were removed because no adapter emits them. The mapping from a domain value to a variant is a tested selector in the entity layer, never an import of the domain type into a presentational component.

The same variant, rendered twice. Fill and a solid dot mean the value is current. Outline and a hollow dot mean the robot stopped reporting and this is the last thing it said.

05 — Freshness

Age travels with value

Freshness is derived on a timer rather than on arrival, because the transition that matters is caused by nothing arriving. It is not a status and does not share the status palette.

06 — Controls

Navigation and recovery only

There are no command controls anywhere in this system. A command surface implies requested, acknowledged, executing, completed, failed and unknown as distinct states plus an audit trail, and a button reporting success it cannot verify is the exact failure this project argues against. Every control below either changes what is shown or forces a transport attempt whose result is visible.

Connection integrity

Retry forces an immediate attempt and increments the visible counter. A control that does nothing is a smaller version of the same lie.
